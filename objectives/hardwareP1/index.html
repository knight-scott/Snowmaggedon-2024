    Solution⚓︎

    First thing to do for this challenge is assemble our hint. The provided link gives a python script and after unzipping the shreds.zip from Frosty's Keypad we have a directory named slices with 1000 .jpg files. Make sure that the .py script is in the same directory as the slices directory. When I ran the script, I got notices about not having the necessary packages, specifically numpy and PIL. Use pip install numpy and pip install Pillow if you run into similar errors.

    Virtual Environment

    If you haven't been doing so, it's a good idea to work from a virtual environment. From your working directory, use python3 venv venv then source venv/bin/activate to start your virtual environment before installing the script or dependencies it requires.

    Once the dependencies are installed, the script should run without issue and produce a .jpg file

    It's not a very useful image though, so lets open it with an image manipulator and see if it can be improved. Open the image with most any editing tool and use the orientation tools to flip the image horizontally to get a more easily read image:

    With the above image we now have some clues for how to proceed with the first part of the challenge; setting up the UART properly.

    Based on the manual, we have an access card management system (Sanata's Little Helper) and it's interface, the UART. We also have images of important settings for the bridge device. We should make note of the voltage toggle switch, set to 3V in the manual and the PIN header labels:
    VCC- Voltage
    TX - Transmit
    RX - Reveive
    GND - Ground

    Closing the manual, we see four colored cables that can be connected between the bridge and the UART board, plus a USB cable that needs to be connected to the bridge from the terminal. On the UART board we see G, R, T, V next to the pins.
    Lets assume G = Ground and use the black cable to connect the G pin to the GND pin on the bridge:

    Continuing along, use the red cable to connect the V pin to the VCC pin on the bridge.

    The other two pins on the bridge are TX for transmitting and RX for receiving. The UART board has corresponding T and R. It may seem sensible to connect TX to T however this would mean both the UART and the bridge are transmitting to each other on the same line. Instead, connect the bridge TX transmit pin to the UART R receiving pin, and the bridge RX receiving pin to the UART T pin.

    Check the source

    If you take the time to check the source code early on, you would find the pin connections listed as well.

    Finally, connect the USB cable to the bridge from the interface and toggle the voltage switch to 3V before selecting the 'Zoom in' option for the interface.
