    Frosty Keypad (Gold)⚓︎

    Difficulty:
    Direct link: Frosty Keypad

    Objective⚓︎

    Gold

    There is another numerical access code needed to access the Shredder McShreddin 9000 and collect the "crucial document we need to access Santa's chest"

    Hints⚓︎

    Shine Some Light on It

    Well this is puzzling. I wonder if Santa has a seperate code. Bet that would cast some light on the problem. I know this is a stretch...but...what if you had one of those fancy UV lights to look at the fingerprints on the keypad? That might at least limit the possible digits being used...

    Solution⚓︎

    The hint above proved to be pointing to another item for collection, a UV Flashlight, that when selected and pointed at the keypad, showed "fingerprints" on the numbers used, plus the "Enter" button. Only the numbers used for the Silver accomplishment show fingerprints (8-7-6-2) as well as the "Enter" button, indicating that the same numbers are used in a different configuration for the second access code. We only have four numbers, but since Silver reused a number it can be assumed that the Gold access code will reuse at least one digit as well.

    My first unsuccessfull attempts at cracking the keypad involved trying to come up with a holdiay/Santa themed word list 5 characters long from the 13 possible characters represented by the numbers 2, 6, 7 and 8. That quickly proved fruitless and I reevaluated. Lets send our known good access code with BurpSuite. First, the keypad should be in a seperate window.     If we right-click and select "Send to Intruder" we can use BurpSuite to craft an attack that will send the above POST /submit packet with every variation of our answer.

    We'll need a payload to use. In this case, a text file with each possible 5 digit number on a sepearate line. I wrote a python script to create a wordlist. The one here represents a modified version that was adjusted after I did things the hard way.

    from itertools import permutations

# Known digits from successful password
digits = "72682"

# Generate all unique permutations of the digits
# Permutations inherently avoid duplicates
combinations = [''.join(p) for p in permutations(digits, 5)]

# Filter combinations to ensure each digit is used at least once
valid_combinations = [
    combo for combo in combinations if all(digit in combo for digit in digits)
]

# Write valid combinations to a file
with open("access-code_list.txt", "w") as file:
    file.write("\n".join(valid_combinations))

print(f"Generated {len(valid_combinations)} valid combinations.")

    With our list in hand, we can return to BurpSuite's Intruder and begin the attack. Ensure you have selected "Sniper attack" from the drop-down. Highlight the answer at the bottom of the packet and click the "Add" button to tell BurpSuite what our target is. This is the part of the packet that we will have BurpSuite test using the list of options created by our scipt.

    In the "Payload configuration" window click 'Load...'

    Select the list that was created by the script.

    We're ready to click "Start attack".

    If you are using the free community version of BurpSuite you will likely see the following pop-up:

    This works in our favor here. With only 120 possibilities, it doesn't take long even with the rate limiter. Furthermore, we don't have to worry as much about counter-tactics to prevent this kind of attack. Once Start attack has been clicked, BurpSuite will begin testing each number in your list, sending the packet from our successful access code and changing the payload that was highlighted with each option in the list we provided. You'll be able to watch each number in real time and see the response code that is returned. We are expecting a lot of 400 and looking for 200.

    Now we can input the code we found in the keypad and select "Enter"

    Admonitions⚓︎

    Attention to detail

    When writing a script for a wordlist like this, be sure to take all of the factors into account. Working with a lack of sleep, my original script did not account for duplicates, or obvious failures such as a number that is all of one digit or didn't contain at least one of each of the four numbers. This resulted in a list of 3124 possible combinations. The script above takes those factors into account and produces a much smaller list of 120 possible combinations.
