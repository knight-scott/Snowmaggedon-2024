    Elf Connect (Silver)⚓︎

    Difficulty:
    Direct Link: Elf Connect

    Objective⚓︎

    Help Angel Candysalt connect the dots in a game of connections.

    Welcome to Elf Connect!
    This game is based on the popular New York Times 'Connections' game.

    The game has 4-rounds. For each of the 4 rounds, you are presented with 16 words.

    Each round is based on a theme. The theme can be further grouped into sub-topics.

    The theme could be pets, but the groups could be dog breeds, cat breeds, etc.

    The object of the game is to group words that share a common thread.

    You receive 100 points for each row you complete. Go for gold and try to beat the high-score.

    Angel Candysalt

    Welcome back, island adventurer! I'm Angel Candysalt — so happy to finally meet you!
    I'm thrilled you're here because I could really use a hand with something.
    Have you ever heard of a game called Connections?
    It’s simple! All you need to do is find groups of four related words.
    I've been stuck on it all day, and I'm sure someone as sharp as you will breeze through it.
    Oh, and while you're at it, check out randomElf's score — they hit fifty thousand points, which seems… oddly suspicious.
    Think they might have tampered with the game? Just a hunch!

    Hints⚓︎

    Elf Connect Easy

    I love brain games! This one is like the New York Times Connections game. Your goal here is to find groups of items that share something in common. Think of each group as having a hidden connection or theme—four items belong together, and there are multiple groups to find! See if you can spot patterns or common threads to make connections. Group all the items correctly to win!

    Solution⚓︎

    This was the first challenge I came across on Frosty's Beach. As with each of the challenges so far, it could be done without any manipulation of the site or code to unlock the Silver trophy. A 'simple' matching game, each level could be solved with OSINT practices or even trial and error if you don't know the correct groupings. The game was four levels each with a 4x4 grid of related tiles laid out in a randomized order. Selecting 3 tiles would highlight each selected tile and selecting the 4th tile would move the group of tiles to the top of the grid, if the selections are correct, until each row has been grouped.

    I played through the game completely the first time, taking time to look up how some of the different levels were related that I was unfamiliar with. After the first level of holdiay themes, levels 2, 3, and 4 were more security focused. Since this is a hacking challenge however, there are more interesting options for arriving at the same result so lets look at the one I found when documenting this challenge. I'll show how I found this particular exploit, as well as some of the source code that explains why this works.

    Once all 4 groups have been properly selected the game plays a little fireworks sequence and loads the next level. There are a couple of points to note here:
    1. The game can be played from a "terminal" on Frosty's Beach, which opens a pop-up of the game, or it can be opened in a seperate browser window.
    2. If played in an independent window, the current level is displayed in the URL:
    https://hhc24-elfconnect.holidayhackchallenge.com/?round=1

    While capturing screenshots for this write up to illustrate the game action when the level completes, I had call to change the round from '2' to '1' which reloaded the page to show the tiles for round 1. I completed the level again, setting up my screenshot to capture the "Round 1 Complete" fireworks.

    That was interesting. The fireworks screen says "Round 2 Completed". Obviously, I had to investigate further. The URL had changed, showing /?round=3, with the tiles reflecting the same while my score count was showing 800 points, the same amount as completing two levels. I changed the URL to round=1 once again and quickly completed the matches. Sure enough, "Round 3 Complete" with fireworks played before round four tiles loaded.

    So now I'm theoretically on round 4 as the image and URL above shows. Once again, I changed the "round=" element to reflect round 1 to load the first set of tiles. As can be seen below, the points continue to match those showing above, while the URL and tiles match those seen during round 1.

    I completed the level one more time to trigger the round completetion fireworks:

    Silver Elf Connect

    Congratulations! You have completed the [Silver] Elf Connect challenge!

    That worked! Elf Connect is completed. This unlocks further dialog with Angel Candysalt, the silver trophy, as well as the prompt for how to unlock the Gold trophy.

    Angel Candysalt

    Amazing! You really connected all the dots like a pro.

    Validation

    Having already completed the challenge as intended, I wasn't sure if the bug would still trigger the trophy. To confirm, I asked a cohort member to test it using an unused profile. Their test verified that the bug reliably awards the silver trophy.

    Reflection⚓︎

    Why did that work though? Obviously, that's not "supposed" to happen in a leveling game. You don't want your player receiving the rewards of completing a level when they are replaying the first level over and over.

    We can also see the answer key:

    This shows that each level has the same answer key for each set. As long as the elements submitted as the answer are grouped into the arrays seen here, it doesn't matter what which words are showing on the tiles. This explains why the answers provided after changing the 'rounds=' value are working to advance to the next level. Furthermore, the server recieving the information does not appear to have any checks in place to safeguard against these or account for them.

    Checking the code

    The hint from Angel for Elf Connect Hard suggest looking at the code, at which point you would likely see the answer key and wordlists as well. If you play the matching game before checking the code, this is a humorous reminder to inspect the code before spending a lot of unnecessary time poking around.
