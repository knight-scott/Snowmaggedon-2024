    Difficulty:
    Direct link: PowerShell terminal

    Objective (Silver)⚓︎

    Request

    Team Wombley is developing snow weapons in preparation for conflict, but they've been locked out by their own defenses. Help Piney with regaining access to the weapon operations terminal.

    Piney Sappington

    Hey there, friend! Piney Sappington here.

    You've probably heard the latest—things are getting tense around here with all the faction business between Wombley and Alabaster. But, let’s focus on this PowerShell Terminal for now.

    This is the remote access for our snowball weaponry. We programmed some defense mechanisms to deter intruders, but the system is in a faulty lockdown state.

    I certainly wasn't the one that programmed the mechanism. Nope not me. But can you help me find a way through it so I can regain access?

    There's two functions I need access to. The snow cannon terminal, which should be easier. And the snow cannon production and deployment plans. That one's better defended.

    Still, I've got faith in you. We need every advantage we can get right now, and you might be just the one to tip the balance.

    So, think you can do it? Are you ready to show what you've got?

    Hints⚓︎

    PowerShell Admin Access - Total Control

    I overheard some of the other elves talking. Even though the endpoints have been redacted, they are still operational. This means that you can probably elevate your access by communicating with them. I suggest working out the hashing scheme to reproduce the redacted endpoints. Luckily one of them is still active and can be tested against. Try hashing the token with SHA256 and see if you can reliably reproduce the endpoint. This might help, pipe the tokens to Get-FileHash -Algorithm SHA256.

    Help or Hint

    Type help or Get-Help <cmdlet-name> -Online to get PowerShell assistance. Type hint to get a hint about the current question

    Solution⚓︎

    We are back to a terminal emulator, with a welcome message and a prompt for how to get hints:

    PowerShell is not something I was familiar with before starting this challenge, so while the answers are straightforward in the way they are presented, this challenge required a lot of collaboration and research for both Silver and Gold. One thing that was critical once I got this far into the competition was taking notes. This particular terminal would disconnect often and then start over at question one. Having good notes allowed me to not get stuck repeating the same research or trail and error that I had previously attempted.

    Due to the nature of this challenge, I will list the questions and answers; if you are looking for walkthroughs or in depth analysis, there are a number of great resources easily found with a search online. Lets get into it.

    There is a short delay between submitting your answer and the progression to the next question. If you are stringing commands together to get to the question you are currently on, be aware that you will need to work in a pause to account for this.

    6) There are too many endpoints here. Use a loop to download the contents of each page. What page has 138 words? When you find it, communicate with the URL and print the contents to the terminal. 
    # Define admin credentials explicitly
$username = "admin"
$password = ConvertTo-SecureString "admin" -AsPlainText -Force
$adminCredentials = New-Object System.Management.Automation.PSCredential($username, $password)

# Loop through the pages from 1 to 50
for ($i = 1; $i -le 50; $i++) {
    $url = "http://127.0.0.1:1225/endpoints/$i"

    try {
        # Send the request with the credentials and AllowUnencryptedAuthentication
        $response = Invoke-WebRequest -Uri $url -Credential $adminCredentials -AllowUnencryptedAuthentication -ErrorAction Stop

        # Print out the status and content length to help with debugging
        Write-Host "Requesting $url"
        Write-Host "Status Code: $($response.StatusCode)"
        Write-Host "Content Length: $($response.Content.Length) bytes"

        # Count words in the response content using the suggested method
        $wordCount = ($response.Content | Out-String) -split '\s+' | Where-Object { $_ -ne "" } | Measure-Object | Select-Object -ExpandProperty Count

        Write-Host "Word Count: $wordCount"

        # Check if the word count matches the target
        if ($wordCount -eq 138) {
            Write-Host "Page $i has $wordCount words."
            Write-Host "Contents of the page:"
            Write-Host $response.Content

            # Pause the script here so you can read the content
            Read-Host -Prompt "Press Enter to continue..."
            break
        }
    }
    catch {
        # If there's an error, print the exception message
        Write-Warning ("Error accessing " + $url + ": " + $_.Exception.Message)
    }

    # Wait for 1 second between requests
    Start-Sleep -Seconds 1
}

# Send the request with the endpoint, token in the cookie, and credentials for authentication

# Output the response content

$mfaValidationUrl = "http://127.0.0.1:1225/mfa_validate/$endpoint"
